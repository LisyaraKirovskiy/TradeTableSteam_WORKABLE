---------------------------------------------------------------------------------------------------------------------------------------------
Данная программа помогает отслеживать ваши инвестиции в Steam, а конкретно по играм CS2, Dota 2, RUST, TF2
Как это работает - исходя из заданных вами данных (игра, название, количество, стоимость за единицу товара)
формируется ссылка на предмет, по этой ссылке парсится информация о нем:
-Актуальная цена на торговой площадке
-Картинка предмета.

Далее парсится актуальный курс валюты в которой предмет выставлен на торговую площадку (зачастую это USD) и 
всё это пересчитывается, после чего мы получаем актуальную стоимость в рублях по последнему курсу.
Далее идут вычисления остальных моментов которые отображает программа.
Всё записывается в базу данных.
Так же присутствует формирование графиков исходя из изменения актуальной цены на предметы,
формируется график и сохраняется в виде картинки, затем эта картинка используется программой для отображения полученного графика.
Так же для графиков выведен отдельный класс и база данных.

Всё выполнено через MVVM паттерн с использованием реактивности на основе Avalonia UI, базы данных Sqlite,
Библиотеки для парсинга AngleSharp, ScottPlot для работы с графиками.

Почему именно эта программа? 
Я интересуюсь инвестициями в Steam, подобные таблицы в онлайн формате встречал, не готов 
платить за то что могу сделать сам, собственно так и пришел к этой идее. Самый главный плюс этой программы в том,
что не нужна никакая авторизация и никто не сможет получить данные от аккаунта, когда на таких сайтах она требуется
обязательно и можно нарваться на фишинг.

Решение состоит из 5 проектов.

-ItemDatePrice.Model
Содержит в себе класс (модель) (ItemDatePrice.cs) для сохранения, удаления и получения данных из базы данных.

-Items.BLL
Содержит в себе класс сервиса (Service.cs) для работы с базой данных, а так же интерфейс который реализует его работу (IService.cs).

-Items.DAL
Содержит в себе класс SqliteDb.cs где сформированы основные sql запросы для баз данных.
SqliteHelper.cs помогает сократить повторяющийся код который мог быть в SqliteDb.cs.
Интерфейс ICrud реализует основные функции базы данных CREATE READ UPDATE DELETE.

-Items.Model
Содержит в себе класс Item.cs по которому ведется вся работа программы. Именно эти данные заполняются благодаря парсингу 
и основным рассчетам.
Класс ImageHelper.cs необходим для того чтобы корректно отображать картинки в самой программе.

-testgraph
Папка Assets содержит основные иконки программы чтобы пользователю было удобно ориентироваться где куда и что нажать.
Папка PlotGraphics содержит графики созданные ScottPlot которые обновляются и сохраняются в эту же папку.
Класс SoldFor.cs нужен для того чтобы отображать то на сколько рублей человек продал предметов. Так же 
используется база данных, данные берутся от туда, обновляются там и обнуляются там же.
Папка ViewModels содержит MainWindowViewModel.cs, где прописаны основные функции и логика для правильной работы MVVM.
Папка Views содержит в себе разметку приложения (MainWindow.axaml), а так же логику работы этой разметки в файле
MainWindow.axaml.cs. Так же в папке Views находятся стили Styles.axaml, создавалась для удобства.

Свод по основным переменным.
_expanders - Коллекция всех предметов которые загрузились из базы данных хранится именно в этой переменной.
_service - Необходим для удобной работы с БД.
SelectedItem - Переменная равная выбранному в программе предмету.
FullCost - Общее количество затраченных денег на инвестиции.
NowCost - Актуальная стоимость всех предметов без комиссии.
Profit - Прибыль не чистая.
ClearProfit - Чистая прибыль.
SoldFor - Переменная необходимая для подсчета стоимости продаж предметов.
_SoldForColor - Переменная необходима для определения цвета стоимости продаж предметов.
SoldForString - Переменная для правильного отображения стоимости проданных предметов (добавляется руб.)
_TextColorUpper - Переменная для определения цвета прибыли.
_isRefreshing - Переменная для отображения полосы загрузки при обновлении.

Свод по функциям.

MainWindowViewModel.cs :

Load() - получает данные о предметах из базы данных, добавляет их в _expanders. Так же устанавливает значения
для FullCost, NowCost, Profit, ClearProfit, SoldFor, SoldForString, TextColorUpper.
DeleteAsync() - асинхронная задача для того чтобы удалить предмет как из _expanders, так и из баз данных +
удаляет график этого предмета.
SellAsync() - асинхронная задача для того чтобы продать предмет. Так же удаляет всё из баз данных + график.
RefreshAllAsync() - асинхронная задача обновляет все предметы, заново парсит их и сверяет старые цены с новыми, 
если они меняются, то все данные везде перезаписываются.
RefreshAsync() - асинхронная задача обновляет 1 выбранный предмет, так же используется чтобы поменять закупочную цену или количество.
AddToExpanders() - простая функция добавления какого-то предмета в _expanders.
NullSoldFor() - обнуление счетчика стоимости проданных предметов.
GameRewrite(string game) - костыль для перезаписи игры из краткого вида как в БД в полный для повторного парсинга.

MainWindow.axaml.cs :

CreateOrUpdateGraphics(string connectionString)- функция для загрузки графиков, их сохранения и изменения для каждого предмета.

ButtonSoldDelete_OnClick(object? sender, RoutedEventArgs e) - кнопка для обнуления стоимости проданных предметов.

Item.cs :

Переменные:
Id - Id.
ItemName - Название предмета.
Count - Количество купленных предметов.
Url - Ссылка на предмет.
PurchasePrice - Закупочная цена предмета за единицу.
SteamPrice - Актуальная цена в Steam за 1 единицу.
Currency - Валюта.
SteamPriceWithFee - Актуальная цена в Steam с комиссией за 1 единицу.
StatPrice - Актуальная стоимость всех закупленных предметов одного типа без комиссии.
StatPriceWithFee - Актуальная стоимость всех закупленных предметов одного типа с комиссией.
FullStatPrice - Актуальная стоимость исходя из вычитания актуальной стоимости и закупочной без комиссии.
FullStatPriceWithFee - Актуальная стоимость исходя из вычитания актуальной стоимости и закупочной с комиссией.
FullStatPricePercent - Процентное отношение актуальной стоимости с комиссией и закупочной цены всех предметов.
Image - Ссылка на картинку.
Spent - Потрачено денег на закупку.
Game - Из какой игры предмет.
TextColor - Цвет текста исходя из минуса или плюса по полной статистике.
GraphicImagePath - Картинка с графиком.
ImageUrl - Картинка с предметом.

Функции:
UpdateFrom(Item source) - заменяет старый предмет на новый при изменении цены.
TotalParse(string name,string count,string price, string game) - парсит информацию о предмете, данная задача
объединяет в себе несколько функций для комфортного использования парсинга.
SetSpent() - считает потраченные деньги на все предметы одного типа.
SetNameCountPrice(string name,string count,string price) - ItemName, Count, PurchasePrice.
SetItemName(string name) - устанавливает ItemName.
SetCount(string count) - устанавливает Count.
SetUrl(string game) - формирует ссылку на предмет Url исходя из Game.
SetPurchasePrice(string purchprice) - устанавливает PurchasePrice.
SetSteamPrice() - парсит SteamPrice, Currency, Image, считает SteamPriceWithFee.
SetStatPrice() - считает StatPrice, StatPriceWithFee за один предмет.
SetFullStatPrice() - считает FullStatPrice, FullStatPriceWithFee,FullStatPricePercent за все купленные предметы одного типа.
PriceToDouble(string price) - перевод из string в double.
ConvertCurrency(string currency)- конвертирует валюту из валюты которая получена в рубль.
